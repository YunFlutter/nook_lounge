# Google Sheets QA 시트 사용법

권장 파일: `docs/qa_google_sheet_detailed.csv`

대체 파일: `docs/qa_google_sheet_detailed.tsv`

## 가져오기
1. Google Sheets에서 새 시트를 엽니다.
2. `파일 > 가져오기 > 업로드`로 `docs/qa_google_sheet_detailed.csv`를 업로드합니다.
3. 가져오기 옵션은 `새 스프레드시트 만들기` 또는 `현재 시트 바꾸기`를 선택합니다.
4. CSV가 잘 열리지 않는 경우에만 `docs/qa_google_sheet_detailed.tsv`를 업로드하고 구분자를 `탭`으로 지정합니다.

## 체크박스 적용
1. 가져온 시트에서 `C:F` 열을 선택합니다.
2. `삽입 > 체크박스`를 누릅니다.
3. `C=실행`, `D=PASS`, `E=FAIL`, `F=보류` 컬럼이 체크박스로 바뀝니다.

## 추천 세팅
1. 1행 고정
2. 필터 만들기
3. 조건부 서식 추가
   - `D열 PASS` 체크 시 초록
   - `E열 FAIL` 체크 시 빨강
   - `F열 보류` 체크 시 노랑
4. 보기 필터 예시
   - `우선순위 = P0`
   - `라운드 = R1 Smoke`
   - `기능 영역 = 마켓`

## 운영 팁
1. `실행`만 체크된 상태면 테스트 진행 중으로 봅니다.
2. `PASS/FAIL/보류` 중 하나만 체크하도록 운영 룰을 정하면 관리가 편합니다.
3. 버그가 나오면 `버그ID`에 티켓 번호를 넣고 `증적`에 스크린샷 링크를 적습니다.
